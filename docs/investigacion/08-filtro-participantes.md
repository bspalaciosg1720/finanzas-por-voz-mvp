# Filtro de participantes

## Objetivo de la muestra

Reclutar personas que administren gastos personales desde un teléfono y hayan
intentado controlar sus finanzas, sin limitar la muestra a usuarios expertos.

## Preguntas de selección

### 1. Edad

- [ ] Menor de 18 años → excluir.
- [ ] 18–21 años → reserva.
- [ ] 22–45 años → segmento principal.
- [ ] Mayor de 45 años → incluir hasta dos para observar accesibilidad.

### 2. País y moneda principal

- País:
- Moneda utilizada con mayor frecuencia:

Priorizar Colombia y COP durante esta fase.

### 3. ¿Cómo controlas actualmente tus gastos?

- [ ] Aplicación financiera.
- [ ] Hoja de cálculo.
- [ ] Notas o chat personal.
- [ ] Extracto bancario.
- [ ] Memoria.
- [ ] No los controlo.

Incluir variedad de métodos.

### 4. Durante los últimos seis meses, ¿intentaste registrar gastos?

- [ ] Sí, lo hago actualmente.
- [ ] Sí, pero abandoné.
- [ ] No.

Priorizar una combinación de usuarios activos y personas que abandonaron.

### 5. ¿Con qué frecuencia realizas pagos personales?

- [ ] Menos de uno por semana.
- [ ] Entre uno y cinco por semana.
- [ ] Más de cinco por semana.

Excluir únicamente si casi nunca realiza movimientos personales.

### 6. ¿Qué tipos de pagos utilizas?

- [ ] Efectivo.
- [ ] Transferencias.
- [ ] Tarjeta débito.
- [ ] Tarjeta crédito.
- [ ] Billetera digital.

Buscar diversidad; no utilizar esta respuesta como criterio único.

### 7. ¿Trabajas profesionalmente en contabilidad o control financiero?

- [ ] Sí → excluir del segmento principal o registrar como experto.
- [ ] No.

### 8. ¿Tu necesidad principal es administrar finanzas empresariales?

- [ ] Sí → excluir del MVP personal.
- [ ] No.

### 9. ¿Puedes participar en una sesión remota o presencial de 35 minutos?

- [ ] Sí.
- [ ] No.

### 10. Consentimiento de contacto

- [ ] Acepta ser contactado únicamente para coordinar la sesión.

## Cuotas sugeridas para diez entrevistas

| Característica | Cuota |
|---|---:|
| Abandonó un método de registro | 4–6 |
| Registra actualmente | 3–5 |
| No registra, pero quiere hacerlo | 1–3 |
| Trabajo independiente | 3–5 |
| Empleo asalariado | 3–5 |
| Más de cinco pagos semanales | ≥6 |
| Usa efectivo regularmente | ≥3 |

## Datos que no deben solicitarse

- Ingresos exactos.
- Saldo bancario.
- Número de cuenta.
- Institución financiera.
- Deudas identificables.
- Dirección.
- Documento de identidad.
