# Checklist del piloto

Ejecutar una sesión piloto interna antes de entrevistar participantes.

## Preparación técnica

- [ ] El prototipo abre en el teléfono.
- [ ] Los seis escenarios pueden reiniciarse.
- [ ] La navegación inferior responde.
- [ ] La corrección de categoría funciona.
- [ ] El monto ambiguo puede resolverse.
- [ ] El estado de error permite reintentar.
- [ ] El cronómetro está preparado.
- [ ] La grabación, si fue autorizada, funciona.
- [ ] Existe un método alternativo para tomar notas.

## Preparación metodológica

- [ ] El moderador lee la introducción sin vender la solución.
- [ ] Las tareas no revelan dónde tocar.
- [ ] Todos los importes y nombres son ficticios.
- [ ] El observador distingue ayuda, error y abandono.
- [ ] Se asigna un código anónimo.
- [ ] Se confirma el consentimiento.
- [ ] Se conoce la fecha de eliminación de grabaciones.

## Criterios para aprobar el piloto

- La sesión dura 35 minutos o menos.
- Las instrucciones se entienden sin reformulación.
- El moderador no guía accidentalmente al participante.
- Cada tarea produce una observación medible.
- Los resultados pueden registrarse en el CSV.
- El analizador genera el informe sin modificar manualmente su estructura.
